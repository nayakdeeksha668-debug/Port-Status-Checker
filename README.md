
# Port Status Checker

## Project Description
Port Status Checker is a Python-based networking tool
that checks whether specific TCP ports are open or
closed on a target IPv4 address.

It helps beginners understand basic network
communication and port availability.

## Features
- Check a single port.
- Scan multiple common ports.
- Identify open and unreachable ports.
- Validate IPv4 addresses.
- Validate port numbers.
- Display colorful terminal results.
- Generate an automatic scan report.

## Technologies Used
- Python
- Socket Library
- IP Address Validation
- VS Code

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run:

   python port_checker.py

6. Enter an IPv4 address.
7. Select a scanning option.

## Project Files

- port_checker.py - Main Python program.
- scan_report.txt - Generated scan report.
- README.md - Project documentation.

Target IP: 127.0.0.1

Open Ports: 2
